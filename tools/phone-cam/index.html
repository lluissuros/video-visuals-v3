Apaisado (horizontal) para que la imagen llene la pantalla. Deja la página delante: al fondo, el móvil corta la cámara. El cuadrado manda palette (→) y saturación (↑) a las pantallas, con o sin cámara.
¿El navegador avisa de conexión no segura? Instala una vez el certificado y no volverá a avisar (ningún navegador, tampoco Arc).
Android: descarga, luego Ajustes → Seguridad → Cifrado y credenciales → Instalar un certificado → Certificado de CA → elige el archivo. El aviso «la red puede estar supervisada» es normal.
iPhone: ábrelo en Safari → Permitir → Ajustes → Perfil descargado → Instalar. Después Ajustes → General → Información → Config. de confianza de certificados → activa «video-visuals phone-cam CA».
